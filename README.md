## 关于我

你好，我是 Ming。

我更关心一个想法能不能真正做出来，并送到用户手上。在做项目时，我习惯从需求拆解、全栈实现、服务部署到最终交付一路推通，用解决问题的结果来证明技术价值。

目前主要关注并实践的方向：

- **全栈独立开发**：完整负责产品的前后端实现与云端部署，追求高效与自主交付。
- **Web 安全与协议**：深入网络协议与常见漏洞分析，利用自动化手段提升安全分析与挖洞效率。
- **视觉与氛围表达**：关注视觉设计与审美，将个人摄影风格融入内容呈现中。

## 经验概览

- **全栈开发与独立交付**：独立开发并上线一款非营利校园小程序，承载 `1,000+` 真实用户，完整负责从前端、云端部署到产品交付的全流程。
- **商户合作与业务落地**：拓展校园周边商户合作，在小程序内成功落地数字化代金券的对接与分发。
- **Web 安全与漏洞挖掘**：熟悉网络协议与常见 Web 漏洞，结合自动化脚本进行安全分析，曾向漏洞盒子及企业 SRC 平台提交过有效漏洞。
